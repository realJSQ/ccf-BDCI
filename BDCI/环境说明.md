## 使用

本次会话已启动服务，浏览器访问 <http://localhost:5173>。服务停止后可重新启动：

```bash
cd /home/jsqke/lpyproject
source BDCI/activate.sh
jiuwenswarm-start
```

前台运行时按 Ctrl+C 停止；也可以在另一终端执行：

```bash
cd /home/jsqke/lpyproject
source BDCI/activate.sh
jiuwenswarm-start --stop default
```

各服务仅绑定本机地址：Web UI 5173、AgentServer 18092、WebChannel 19000、Gateway 19001。端口冲突时上游可能自动换用另一组端口，以启动输出为准。Codex 沙箱禁止监听 socket，本次启动验证使用了获准的沙箱外执行；在正常 WSL 终端可使用上述命令。

## 复现安装要点

官方说明保存在 `setup/Quickstart.upstream.md`，依赖清单快照为 `setup/pyproject.toml`，与本次源码版本一致。本次使用以下安装流程：

```bash
# 已有源码和 Python 虚拟环境时
source /home/jsqke/lpyproject/BDCI/activate.sh
uv pip install --python "$VIRTUAL_ENV/bin/python" -e "$BDCI_ROOT/jiuwenswarm"
cd "$BDCI_ROOT/jiuwenswarm/jiuwenswarm/channels/web/frontend"
npm ci --no-audit --no-fund
npm run build
jiuwenswarm-init
jiuwenswarm-start
```

不建议在比赛期间直接追踪最新 develop：上游依赖中的 `agent-protocol` 还引用可变分支，重新解析时可能产生版本漂移，应结合本次源码 SHA 和依赖快照固定后续实验环境。
