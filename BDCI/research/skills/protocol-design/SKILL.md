# Operational protocol design

Native SwarmFlow skill for converting a research-agent proposal and checked
literature into an executable development protocol. The designer can decline;
the auditor can reject. Neither JSON validation nor an approving model is a
scientific acceptance certificate. This skill does not execute experiments.

Run `python BDCI/research/run_protocol_design.py` for a scripted integration
fixture; `--live` uses two requests from the existing research-v2 ledger.
See `prior_work/revision_followup.json` for the assistant-supplied evidence
and methodological corrections. Preserve the original proposal verbatim.
