# JiuwenSwarm 科研论文自动生成赛题

核对日期：2026-09-29。已读取官方公开接口的完整赛题、数据评测、FAQ 与结构化日程，原始资料及 URL/UTC/哈希见 [核对记录](docs/submission/official-rules-20260929/source-index.json)。官方入口为 <https://www.xir.cn/competitionApi/api/competitions/1167>；不能把浏览器返回的 SPA 空壳当作完整要求。

## 必须满足

- 基于 openJiuwen 社区开源代码开发，**必须修改 JiuwenSwarm 源码，否则作品无效**。
- 开发面向 Agent 前沿技术研究的科研论文自动生成系统。网页推荐单 skill、team skill 或修改 rail 扩展 harness。
- 任务允许论文全流程或半流程自动化，覆盖选题拆解、文献调研、方法设计、论文撰写和结果分析。建议方向为 Agent 上下文工程、记忆引擎、自演进；当前缓存产物恢复研究可定位于上下文工程，但这是项目自身的方向映射，不是主办方认可声明。
- 提交 1 篇英文论文 PDF，使用 ICLR 模板；篇幅不限。
- 提交与最终论文对应的 Stanford Agentic Reviewer Access Token，评审使用 ICLR 标准。该服务存在每日评测数量限制。
- 提交带注释源码、工程说明、运行配置、依赖、复现指南，以及架构、框架模块调用、创新点文档。
- 提交可追溯的 Token 消耗、运行时长统计及日志。
- 提交框架贡献说明和 PR 链接；贡献评分说明还列出 patch 文件等材料，但不可据此假定能免除提交要求中的 PR 链接。
- 获奖选手需将代码开源至指定 AtomGit/GitCode 仓库：<https://gitcode.com/openJiuwen/agent-store>。

## 提交目录

ZIP 文件及顶层目录以团队名称命名。样例目录和关键文件名保持不变；其他文件可自由组织。

```text
团队名称.zip
└── 团队名称/
    ├── paper/paper.pdf
    ├── AgenticReviewer/PaperReview-AccessToken.txt
    ├── code/
    ├── docs/architecture.md
    ├── docs/module_call.md
    ├── docs/innovation.md
    ├── framework_contribution.md
    ├── resource_report.md
    └── 提交说明.md
```

每天最多提交 3 次，以每个提交周期的最后一次提交为准；初赛按五轮中的最高得分排序。2026-09-29 已进入第五轮，持续至 10-09。报名、组队及团队信息修改截止 **2026-10-09 12:00**；初赛作品截止 **2026-10-09 24:00，北京时间**。赛题结构化日程对应 `2026-10-09T23:59:59+08:00`。10-31 是总赛期末，不是初赛提交截止。官方保留调整赛程权利，提交前仍应关注公告。
